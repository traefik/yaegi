# yaegi conformance tests

Tests imported from the yaegi interpreter (Apache-2.0, see `LICENSE` in this
directory) to measure how much of yaegi's test corpus the VM runs correctly.
They are generated by `scripts/import_yaegi_tests.py` (read-only on a yaegi
checkout); every file is listed with its provenance in `MANIFEST.tsv`
(path, origin `master@<sha>` | `fork:<branch>@<sha>` | `upstream-pr:<N>@<sha>`,
status `added` | `variant`, note). `IMPORT-NOTES.txt` lists what was seen but
not imported.

Directories starting with `_` are ignored by the go tool: nothing here is
built by `go build ./...` or `go test ./...`.

| Directory | Content |
|---|---|
| `_test/` | yaegi's `_test/` at master, unchanged, plus the `_test/` programs added by the fork branches and upstream pull requests listed below |
| `_api/` | yaegi's Go unit tests (public API reference), see `_api/README.md` |
| `_interp-testdata/` | `interp/testdata/` files added by fork branches (per origin) |

## Programs (`_test/`)

Each top-level `_test/*.go` file is a `package main` program whose last
comment is the expectation, as in yaegi's `TestFile`:

```go
// Output:
// 12
```

or `// Error:` followed by a substring of the expected error. A first line
`// GOPATH:testdata/<dir>` runs the program with that GOPATH. Sub-directories
hold local packages imported as `github.com/traefik/yaegi/_test/<dir>`; the
runner (`cmd/runtests`) copies `_test/` into a temporary module named
`github.com/traefik/yaegi` so that these imports resolve.

Sources:

- yaegi `master` (the commit is in `MANIFEST.tsv`);
- fork branches: `ai/fix-upstream-1414`, `ai/fix-empty-typeswitch-clauses`,
  `ai/fix-go-build-constraints`, `ai/fix-upstream-1341`, `ai/fix-upstream-1518`,
  `ai/fix-upstream-1437`, `ai/fix-upstream-1674`;
- open upstream pull requests (upstream-pr: 1737, 1733, 1732, 1730, 1729,
  1727, 1724, 1712, 1711, 1708, 1647, 1638, 1560, 1357, 1265, 1081, 1079),
  compared with their merge base with master.

Naming rules: a file added by a branch or PR under an existing name with a
different content is imported as `<name>.fork-<branch>.go` or
`<name>.upstream-pr<N>.go`; a modified `_test` file is imported (same suffix)
only when its expectation comment differs from master's. Upstream PR 1727 is a
mechanical `interface{}` to `any` rewrite: its modified files are not imported.

The expectations are yaegi's: `Error:` messages are yaegi's wording, while the
VM reports go/types (gc) messages. The runner also accepts gc's wording when
yaegi's `TestInterpErrorConsistency` gives it (`PASS_ERR_GC`).

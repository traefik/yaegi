# Complex plugins: big libraries under yaegi and yaegi v2

The plugins of the public catalog (`compare/catalog`) are small: headers,
regexps, JWTs, some JSON. They were written for yaegi, so they avoid what
yaegi cannot run. This directory holds 20 Traefik middlewares that do what
plugin authors ask for and could not do with yaegi: protobuf and gRPC, LLM
API clients, OpenTelemetry, Redis, policy and expression engines, scripting
engines, the AWS SDK, client-go.

Each plugin is a module in `plugins/<name>/` with a `.traefik.yml`. The
handler is the same in all of them (`common.go`): `New` calls `setup`, and
each request calls `process`, whose result (or error) goes to the header
`X-Complex-Result` of the request seen by next and of the response. Every
plugin works without network: the servers it talks to (LLM APIs, S3, Redis,
an OTLP collector, a gRPC server) are mocks that the plugin starts itself on
127.0.0.1. The outputs do not depend on time or random values (fixed keys,
fixed timestamps, sorted maps), so the transcripts can be compared byte for
byte with a native build.

## Run

```bash
sh compare/complex/vendor.sh   # vendor/ of each plugin (module cache or network)
cd compare && go run ./catalog/run -src complex/plugins -only . -scenarios middleware
```

`-src` makes the catalog runner read the plugins and `COMMITS.tsv` of this
directory instead of `compare/catalog/src`; `-only` keeps it from writing the
results files of the catalog. The transcripts go to
`compare/catalog/out/<name>/` (ignored). The method and the classification
are those of the catalog harness (`compare/catalog/README.md`): a native
build of each plugin runs twice and is the reference; yaegi v0.16.1 is
configured as Traefik configures it; yaegi v2 uses `internal/pluginhost`, with
and without `-aot`.

client-go, OPA, the OpenTelemetry SDK and gopher-lua import `os/exec`, which
the rules of Traefik refuse at load time. `-vmexec mock` loads the yaegi v2
hosts with `Options.Exec = vm.ExecMock` (the plugin may import os/exec, but
no program runs), to see how these plugins run past the rule:

```bash
cd compare && go run ./catalog/run -src complex/plugins -only '^(k8s|opa|otel)$' -scenarios middleware -vmexec mock
```

## The plugins

| plugin | libraries | what it does |
|---|---|---|
| [protobuf](plugins/protobuf/plugin.go) | google.golang.org/protobuf | a message generated by protoc-gen-go (map, oneof, enum, repeated, Timestamp), binary and JSON round trips, Any, Struct, dynamicpb, prototext |
| [grpc](plugins/grpc/plugin.go) | google.golang.org/grpc | gRPC server and client in the plugin: unary call with interceptors on both sides, metadata, status codes, the health service |
| [openai](plugins/openai/plugin.go) | github.com/openai/openai-go/v3 | chat completion with a tool, typed API error, streaming (SSE) with the accumulator, against a mock of the API |
| [anthropic](plugins/anthropic/plugin.go) | github.com/anthropics/anthropic-sdk-go | Messages API with a tool, content block unions, typed API error, streaming and `Accumulate` |
| [otel](plugins/otel/plugin.go) | go.opentelemetry.io/otel (SDK, OTLP/HTTP exporter) | spans with a custom id generator, W3C propagation to next, OTLP protobuf export to a mock collector, counter and histogram read by a manual reader |
| [redis](plugins/redis/plugin.go) | github.com/redis/go-redis/v9, github.com/alicebob/miniredis/v2 | rate limit with a Lua script, pipeline, WATCH transaction, sorted set, pub/sub, `Scan` into a struct; the Redis server is miniredis |
| [expr](plugins/expr/plugin.go) | github.com/expr-lang/expr | rules compiled against a struct of the plugin (fields, methods, maps), closures, `matches`, type errors at compile time |
| [cel](plugins/cel/plugin.go) | cel.dev/cel-go | CEL policies with the strings, math, lists, sets and encoders extensions, optional fields, a Go function |
| [goja](plugins/goja/plugin.go) | github.com/dop251/goja | a JavaScript (ES2015+) router: classes, Map, arrow functions, spread, JSON; Go functions called from JS |
| [lua](plugins/lua/plugin.go) | github.com/yuin/gopher-lua | a Lua script: tables, closures, coroutines, patterns, pcall, a Go function |
| [wazero](plugins/wazero/plugin.go) | github.com/tetratelabs/wazero | a WebAssembly module (written by hand) run by the wazero interpreter, calling back a Go host function |
| [aws](plugins/aws/plugin.go) | github.com/aws/aws-sdk-go-v2 (S3, signer, DynamoDB attributevalue) | SigV4 signing and presigning, S3 Put/Get/List against a mock (XML), NoSuchKey error, DynamoDB marshaling of a plugin struct |
| [prometheus](plugins/prometheus/plugin.go) | github.com/prometheus/client_golang | counter, histogram, summary, gauge, a custom collector, gather and text exposition |
| [opa](plugins/opa/plugin.go) | github.com/open-policy-agent/opa/v1/rego | a Rego authorization policy prepared once and evaluated per request (sets, comprehensions, `net.cidr_contains`, regex) |
| [jose](plugins/jose/plugin.go) | github.com/go-jose/go-jose/v4 | ES256 JWT, nested signed then encrypted JWT (RSA-OAEP-256, A256GCM), JWK set, validation |
| [graphql](plugins/graphql/plugin.go) | github.com/vektah/gqlparser/v2 | a schema, validation of queries, depth, formatter |
| [html](plugins/html/plugin.go) | github.com/yuin/goldmark, github.com/microcosm-cc/bluemonday, github.com/PuerkitoBio/goquery | Markdown to HTML, sanitizing, CSS selectors |
| [k8s](plugins/k8s/plugin.go) | k8s.io/client-go (fake clientset), k8s.io/apimachinery, sigs.k8s.io/yaml | decode a manifest with the scheme, typed clients over the object tracker, label selectors, unstructured, YAML |
| [zap](plugins/zap/plugin.go) | go.uber.org/zap, github.com/rs/zerolog | structured logs with object marshalers into buffers |
| [cbor](plugins/cbor/plugin.go) | github.com/fxamacker/cbor/v2, github.com/vmihailenco/msgpack/v5 | CBOR (toarray, keyasint, canonical, diagnostic) and MessagePack with custom encoders |
